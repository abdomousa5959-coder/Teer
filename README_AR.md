# NEXUS X ULTRA — Authorized Web Security Audit

## الإصدار 5.0.0
منصة Android لتدقيق مواقع الويب التي يملك المستخدم صلاحية اختبارها.

### الوحدات
- تدقيق TLS والشهادة وSAN وسلسلة الشهادات ومجموعة التشفير.
- مراجعة ترويسات HTTP الأمنية: HSTS وCSP وتوجيهاتها وX-Frame-Options وCOOP/CORP/COEP وCORS.
- مراجعة خصائص Cookies دون حفظ قيمها.
- تحليل ساكن محدود لـ HTML وJavaScript وCSS وJSON وXML حتى 512KB لكل استجابة.
- مؤشرات أخطاء SQL وPHP وStack Traces وتسريب المصدر.
- مؤشرات JavaScript الخطرة مثل eval وdocument.write وinnerHTML.
- رصد أنماط مفاتيح AWS والأسرار وكتل المفاتيح الخاصة المكشوفة؛ النتائج تحتاج تحققاً يدوياً.
- تحليل XML لمؤشرات DOCTYPE وExternal Entity declarations دون تشغيل محلل XML أو استغلال XXE.
- مراجعة نماذج كلمات المرور وMixed Content وSRI وiframe وروابط target=_blank.
- تدقيق متعدد الصفحات ضمن نفس النطاق: يبدأ من الروابط الداخلية المعلنة، وrobots.txt وsitemap.xml.
- تقارير JSON تعرض الصفحات التي تمت زيارتها والنتائج لكل صفحة.

### حدود التشغيل والسلامة
- HTTPS فقط وعلى المنفذ 443.
- رفض عناوين IP الخاصة والمحلية بعد DNS resolution.
- نفس النطاق فقط؛ لا يتبع التحويلات إلى نطاقات أخرى.
- حتى 12 صفحة إجمالاً، بطلبات GET فقط، وبحد أقصى 512KB من نص كل استجابة.
- يحترم مسارات Disallow في robots.txt ولا يطلبها.
- لا يرسل النماذج، ولا ينفذ JavaScript، ولا يستخدم payloads أو استغلالاً، ولا يجري brute force أو تخميناً لقوائم مسارات.
- النتائج مؤشرات تدقيق وليست إثباتاً لوجود ثغرة أو غيابها. فحص نسخة إنتاجية يحتاج مراجعة يدوية واختبارات مستقلة.
