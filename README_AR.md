# NEXUS X ULTRA — Android Passive Web Security Audit

## النسخة 3.0
- واجهة سوداء وخضراء بطابع Terminal.
- فحص HTTPS سلبي لعنوان واحد في كل تشغيل.
- تحليل HSTS وCSP (بما في ذلك unsafe-inline وunsafe-eval) وX-Content-Type-Options وX-Frame-Options/frame-ancestors وReferrer-Policy وPermissions-Policy وبعض ترويسات Cross-Origin.
- تحليل خصائص Cookies دون تصدير قيمة الكوكي أو سر الجلسة.
- قراءة شهادة TLS والتحقق من تواريخ الصلاحية ومجموعة التشفير المعلنة.
- كشف وجهة التحويل ونوعها/اختلاف النطاق دون اتباعها تلقائياً.
- تحليل DNS وHTTP status ومعلومات Server.
- درجات خصم مرتبطة بالملاحظات، مع عدد النتائج حسب الخطورة وتصدير JSON.
- HTTPS فقط، المنفذ 443، رفض بيانات الدخول في الرابط ورفض عناوين IP المحلية/الخاصة.
- يتطلب تأكيد أن المستخدم يملك النطاق أو لديه تصريح.

## بناء APK
يستخدم GitHub Actions تلقائياً عند الدفع إلى main. افتح Actions ونزّل artifact باسم `nexus-x-ultra-debug-apk`.

## حدود مهمة
هذه أداة تدقيق سلبي لإعدادات HTTP/TLS الظاهرة في استجابة واحدة، وليست ماسحاً شاملاً لكل الثغرات ولا بديلاً عن اختبار اختراق احترافي. لا يمكن لأي فاحص أن يضمن اكتشاف "كل الثغرات". لا يجري التطبيق استغلالاً، أو brute force، أو تخمين مسارات، أو فحص منافذ، أو اختبار قواعد بيانات. غياب ترويسة لا يثبت وجود ثغرة دائماً، كما أن استجابة 301 لا تمثل بالضرورة إعدادات الوجهة النهائية. راجع كل نتيجة يدوياً ضمن نطاق تملك تصريحاً بفحصه.
