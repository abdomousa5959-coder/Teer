# DEXRAT Android
تطبيق Android أولي لتحليل ملفات APK محلياً.
- واجهة Jetpack Compose داكنة مع شعار مخصص وخلفية Cyber متحركة.
- اختيار APK عبر Storage Access Framework.
- استخراج SHA-256 وجرد ملفات ZIP.
- اكتشاف ملفات DEX ومكتبات Native واستخراج سلاسل URL.
- قراءة اسم الحزمة والإصدار عند دعم Manifest.
هذا إصدار Static Analysis أولي؛ لا يشغّل APK ولا يدعي تحليل Smali كامل أو Dynamic Analysis. استخدمه فقط على تطبيقات تملكها أو لديك تصريح بفحصها.
